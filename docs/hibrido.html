SI SUSPENDE
ESCALÓN 2 · LA NUBE

SI SUSPENDE
ESCALÓN 3 · SE DETIENE

En cuanto un escalón aprueba el examen, se acabó: el juez verifica y la fase se sella. Nadie más cobra.
Regla dura pedida por el operador: sin atajos silenciosos. Si el motor barato está caído, el sistema para y se arregla — no se salta a uno caro a escondidas.
